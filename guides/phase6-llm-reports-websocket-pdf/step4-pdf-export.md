# Phase 6 - Step 4: PDF Export Service

## Why Are We Doing This?

Digital reports live inside the app. But HR directors present to the C-suite in meetings, share with board members via email, and archive reports for compliance. They need a **downloadable, professional PDF** — something they can print, attach, and file.

The PDF transforms the database report into a structured document:

```
┌─────────────────────────────────────────────┐
│   HR INSIGHT AI — Workforce Risk Report      │
│                                              │
│   Team: Engineering (Technology)             │
│   Generated: March 4, 2026                   │
│   Risk Score: 42% [MEDIUM]                   │
│                                              │
├──────────────────────────────────────────────┤
│   EXECUTIVE SUMMARY                          │
│   The Engineering team presents a moderate...│
│                                              │
├──────────────────────────────────────────────┤
│   ACTION PLAN                                │
│   #  Priority         Impact    Timeline     │
│   1  Reduce overtime  HIGH      1-2 weeks    │
│   2  Career paths     HIGH      2-4 weeks    │
│   3  Pulse survey     MEDIUM    2 weeks      │
│                                              │
├──────────────────────────────────────────────┤
│   EMPLOYEE RISK DETAILS                      │
│   Name          Risk Score    Risk Level     │
│   Alice Johnson    78%         HIGH          │
│   Bob Smith        82%         HIGH          │
│   ...                                        │
│                                              │
├──────────────────────────────────────────────┤
│   Generated by HR Insight AI                 │
│   Confidential — Internal Use Only           │
└──────────────────────────────────────────────┘
```

### Why pdfmake?

We already have `pdfmake` installed (Phase 1). Alternatives considered:

| Library | Pros | Cons |
|---------|------|------|
| **pdfmake** ✅ | Declarative JSON layout, tables, styles, no external deps | Less flexible for complex graphics |
| **puppeteer** | Renders HTML→PDF (pixel-perfect) | Requires headless Chrome (500MB+ install) |
| **jsPDF** | Lightweight | Manual positioning, no table support |
| **@react-pdf/renderer** | React components for PDF | Frontend-only, doesn't run in NestJS |

`pdfmake` is the best fit: server-side Node.js, declarative layout, built-in table support, no headless browser needed. For an HR report with text + tables, it's ideal.

### Step A: Create the PDF service

Create `backend/src/reports/pdf.service.ts`:

```typescript
import { Injectable, Logger } from '@nestjs/common';
import PdfPrinter from 'pdfmake';
import { TDocumentDefinitions } from 'pdfmake/interfaces';

/**
 * Generates professional PDF reports from report data.
 *
 * Uses pdfmake with built-in Helvetica fonts (standard PDF fonts,
 * no external font files needed).
 *
 * The PDF structure:
 * 1. Header — title, team name, date, risk score badge
 * 2. Executive Summary — the LLM-generated markdown (converted to text)
 * 3. Action Plan — priorities table with impact/timeline
 * 4. Retention Strategies — bullet list
 * 5. Employee Risk Details — table of all employees with risk scores
 * 6. Footer — confidentiality notice
 */
@Injectable()
export class PdfService {
  private readonly logger = new Logger(PdfService.name);
  private readonly printer: PdfPrinter;

  constructor() {
    // Use built-in PDF standard fonts (no external font files needed)
    this.printer = new PdfPrinter({
      Helvetica: {
        normal: 'Helvetica',
        bold: 'Helvetica-Bold',
        italics: 'Helvetica-Oblique',
        bolditalics: 'Helvetica-BoldOblique',
      },
    });
  }

  /**
   * Generate a PDF buffer from a report with its related data.
   *
   * @param report - The report record with team, user, and action plan
   * @param employees - Team employees (for the risk details table)
   * @param riskSnapshots - Latest risk snapshots per employee
   * @returns Buffer containing the PDF file
   */
  async generatePdf(
    report: any,
    employees: any[],
    riskSnapshots: any[],
  ): Promise<Buffer> {
    this.logger.log(`Generating PDF for report ${report.id}...`);

    // Build a lookup: employeeId → latest risk snapshot
    const snapshotMap = new Map<string, any>();
    for (const snap of riskSnapshots) {
      snapshotMap.set(snap.employeeId, snap);
    }

    const docDefinition = this.buildDocument(
      report,
      employees,
      snapshotMap,
    );

    return this.renderToBuffer(docDefinition);
  }

  // ─────────────────────────────────────────────────────────────────
  // Document builder
  // ─────────────────────────────────────────────────────────────────

  private buildDocument(
    report: any,
    employees: any[],
    snapshotMap: Map<string, any>,
  ): TDocumentDefinitions {
    const riskColor = this.getRiskColor(report.riskScore);
    const riskLabel = this.getRiskLabel(report.riskScore);
    const generatedDate = new Date(report.createdAt).toLocaleDateString(
      'en-US',
      { year: 'numeric', month: 'long', day: 'numeric' },
    );
    const generatedBy = report.generatedByUser
      ? `${report.generatedByUser.firstName} ${report.generatedByUser.lastName}`
      : 'System';

    // Parse action plan JSON
    const actionPlan =
      report.ActionPlan?.planJson || report.ActionPlan?.[0]?.planJson || {};
    const priorities = actionPlan.priorities || [];
    const strategies = actionPlan.retentionStrategies || [];

    return {
      defaultStyle: { font: 'Helvetica', fontSize: 10 },

      // Page header
      header: {
        text: 'HR INSIGHT AI — Confidential',
        alignment: 'right',
        margin: [0, 15, 40, 0],
        fontSize: 8,
        color: '#999999',
      },

      // Page footer with page numbers
      footer: (currentPage: number, pageCount: number) => ({
        columns: [
          {
            text: 'Generated by HR Insight AI | Confidential — Internal Use Only',
            alignment: 'left',
            margin: [40, 0, 0, 0],
            fontSize: 8,
            color: '#999999',
          },
          {
            text: `Page ${currentPage} of ${pageCount}`,
            alignment: 'right',
            margin: [0, 0, 40, 0],
            fontSize: 8,
            color: '#999999',
          },
        ],
      }),

      content: [
        // ── Title Block ────────────────────────────────────────
        {
          text: 'Workforce Risk Assessment Report',
          fontSize: 22,
          bold: true,
          color: '#1a1a2e',
          margin: [0, 0, 0, 5],
        },
        {
          canvas: [
            {
              type: 'line',
              x1: 0,
              y1: 0,
              x2: 515,
              y2: 0,
              lineWidth: 2,
              lineColor: '#1890ff',
            },
          ],
          margin: [0, 0, 0, 15],
        },

        // ── Report Metadata ────────────────────────────────────
        {
          columns: [
            {
              width: '50%',
              stack: [
                {
                  text: [
                    { text: 'Team: ', bold: true },
                    `${report.team?.name || 'Unknown'} (${report.team?.department || ''})`,
                  ],
                },
                {
                  text: [
                    { text: 'Report Period: ', bold: true },
                    `${new Date(report.dateRangeStart).toLocaleDateString('en-US')} — ${new Date(report.dateRangeEnd).toLocaleDateString('en-US')}`,
                  ],
                  margin: [0, 3, 0, 0],
                },
                {
                  text: [
                    { text: 'Generated: ', bold: true },
                    `${generatedDate} by ${generatedBy}`,
                  ],
                  margin: [0, 3, 0, 0],
                },
              ],
            },
            {
              width: '50%',
              alignment: 'right',
              stack: [
                { text: 'Overall Risk Score', bold: true, fontSize: 11 },
                {
                  text: `${report.riskScore}%`,
                  fontSize: 32,
                  bold: true,
                  color: riskColor,
                },
                {
                  text: riskLabel,
                  fontSize: 12,
                  bold: true,
                  color: riskColor,
                },
              ],
            },
          ],
          margin: [0, 0, 0, 20],
        },

        // ── Executive Summary ──────────────────────────────────
        {
          text: 'Executive Summary',
          fontSize: 16,
          bold: true,
          color: '#1a1a2e',
          margin: [0, 0, 0, 8],
        },
        {
          text: this.stripMarkdown(report.summaryText || 'No summary available.'),
          fontSize: 10,
          lineHeight: 1.4,
          margin: [0, 0, 0, 20],
        },

        // ── Action Plan Table ──────────────────────────────────
        ...(priorities.length > 0
          ? [
              {
                text: 'Action Plan — Priorities',
                fontSize: 16,
                bold: true,
                color: '#1a1a2e',
                margin: [0, 0, 0, 8] as [number, number, number, number],
              },
              {
                table: {
                  headerRows: 1,
                  widths: ['auto', '*', 'auto', 'auto', 'auto'],
                  body: [
                    // Header row
                    [
                      { text: '#', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                      { text: 'Priority', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                      { text: 'Impact', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                      { text: 'Timeline', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                      { text: 'Cost', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                    ],
                    // Data rows
                    ...priorities.map((p: any, i: number) => [
                      { text: String(i + 1), alignment: 'center' },
                      {
                        stack: [
                          { text: p.title, bold: true },
                          { text: p.description || '', fontSize: 8, color: '#666666' },
                        ],
                      },
                      {
                        text: p.impact || 'N/A',
                        color: p.impact === 'HIGH' ? '#ff4d4f' : p.impact === 'MEDIUM' ? '#faad14' : '#52c41a',

                margin: [0, 0, 0, 8] as [number, number, number, number],
              },
              ...strategies.map((s: any) => ({

                    bold: true,

                  {
                    text: `Expected impact: ${s.expectedImpact || 'N/A'}`,
                    fontSize: 9,
                    color: '#666666',
                    margin: [0, 0, 0, 3] as [number, number, number, number],
                  },
                  {
                    ul: (s.steps || []).map((step: string) => ({
                      text: step,
                      fontSize: 9,
                    })),
                    margin: [15, 0, 0, 10] as [number, number, number, number],
                  },
                ],
              })),
              { text: '', margin: [0, 0, 0, 10] as [number, number, number, number] },
            ]
          : []),

        // ── Employee Risk Details ──────────────────────────────
        {
          text: 'Employee Risk Details',
          fontSize: 16,
          bold: true,
          color: '#1a1a2e',
          margin: [0, 10, 0, 8],
          pageBreak: 'before' as const,
        },
        {
          table: {
            headerRows: 1,
            widths: ['*', 'auto', 'auto', 'auto', 'auto'],
            body: [
              // Header
              [
                { text: 'Employee', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                { text: 'Risk Score', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                { text: 'Risk Level', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                { text: 'Engagement', bold: true, fillColor: '#1890ff', color: '#ffffff' },
                { text: 'Tenure (mo)', bold: true, fillColor: '#1890ff', color: '#ffffff' },
              ],
              // Data rows — sorted by risk score descending (highest risk first)
              ...employees
                .map((emp) => {
                  const snap = snapshotMap.get(emp.id);
                  const score = snap?.riskScore ?? 0;
                  const level = snap?.riskLevel ?? 'N/A';
                  return {
                    emp,
                    score,
                    level,
                  };
                })
                .sort((a, b) => b.score - a.score)
                .map(({ emp, score, level }) => [
                  { text: emp.name },
                  {
                    text: `${score}%`,
                    color: this.getRiskColor(score),
                    bold: true,
                    alignment: 'center',
                  },
                  {
                    text: level,
                    color: this.getRiskColor(score),
                    bold: true,
                  },
                  {
                    text: emp.engagementScore?.toFixed(1) || 'N/A',
                    alignment: 'center',
                  },
                  {
                    text: String(emp.tenureMonths ?? 'N/A'),
                    alignment: 'center',
                  },
                ]),
            ],
          },
          layout: 'lightHorizontalLines',
        },
      ],

      // ── Page Setup ───────────────────────────────────────────
      pageSize: 'A4',
      pageMargins: [40, 50, 40, 50],
    };
  }

  // ─────────────────────────────────────────────────────────────────
  // Render to buffer
  // ─────────────────────────────────────────────────────────────────

  private renderToBuffer(docDefinition: TDocumentDefinitions): Promise<Buffer> {
    return new Promise((resolve, reject) => {
      const doc = this.printer.createPdfKitDocument(docDefinition);
      const chunks: Buffer[] = [];

      doc.on('data', (chunk: Buffer) => chunks.push(chunk));
      doc.on('end', () => resolve(Buffer.concat(chunks)));
      doc.on('error', (err: Error) => reject(err));

      doc.end();
    });
  }

  // ─────────────────────────────────────────────────────────────────
  // Helpers
  // ─────────────────────────────────────────────────────────────────

  private getRiskColor(score: number): string {
    if (score >= 70) return '#ff4d4f'; // Red — high risk
    if (score >= 40) return '#faad14'; // Orange — medium risk
    return '#52c41a'; // Green — low risk
  }

  private getRiskLabel(score: number): string {
    if (score >= 70) return 'HIGH RISK';
    if (score >= 40) return 'MEDIUM RISK';
    return 'LOW RISK';
  }

  /**
   * Strip markdown formatting for plain-text PDF rendering.
   * Removes bold markers (**), headers (#), and bullet markers.
   * Preserves line breaks and paragraph structure.
   */
  private stripMarkdown(text: string): string {
    return text
      .replace(/#{1,6}\s*/g, '') // Remove # headers
      .replace(/\*\*(.*?)\*\*/g, '$1') // Remove **bold** markers
      .replace(/\*(.*?)\*/g, '$1') // Remove *italic* markers
      .replace(/^[-*]\s/gm, '• ') // Convert markdown bullets to •
      .trim();
  }
}
```

**Why Helvetica instead of custom fonts?**

Helvetica is one of 14 standard fonts built into every PDF reader (Adobe, Chrome, Preview, etc.). Using it means:
- Zero font file dependencies
- Smaller PDF file size (fonts aren't embedded)
- Guaranteed rendering on every device
- No filesystem path issues in production

**Why `pageBreak: 'before'` on the Employee Risk Details section?**

The executive summary and action plan can be 1–2 pages. Starting the employee table on a fresh page ensures it's always clean and not split mid-table awkwardly.

### Step B: Add the PDF endpoint to the controller

Update `backend/src/reports/reports.controller.ts` — add the PDF export endpoint:

```typescript
import {
  Body,
  Controller,
  Get,
  Param,
  Post,
  Req,
  Res,
} from '@nestjs/common';
import { Response } from 'express';
import { Roles } from '../auth/decorators/roles.decorator';
import { ReportsService } from './reports.service';
import { PdfService } from './pdf.service';
import { GenerateReportDto } from './dto/generate-report.dto';

@Controller('reports')
export class ReportsController {
  constructor(
    private reportsService: ReportsService,
    private pdfService: PdfService,
  ) {}

  /**
   * POST /reports/generate
   */
  @Post('generate')
  @Roles('ADMIN', 'HR_MANAGER', 'TEAM_MANAGER')
  generate(@Body() dto: GenerateReportDto, @Req() req: any) {
    return this.reportsService.generateReport(dto, req.user);
  }

  /**
   * GET /reports
   */
  @Get()
  findAll(@Req() req: any) {
    return this.reportsService.findAll(req.user);
  }

  /**
   * GET /reports/:id
   */
  @Get(':id')
  findOne(@Param('id') id: string, @Req() req: any) {
    return this.reportsService.findOne(id, req.user);
  }

  /**
   * GET /reports/:id/pdf
   *
   * Download the report as a professional PDF.
   * Returns a binary PDF file with appropriate headers.
   *
   * The @Res() decorator gives us direct access to the Express response
   * so we can set Content-Type and Content-Disposition headers for download.
   */
  @Get(':id/pdf')
  @Roles('ADMIN', 'HR_MANAGER', 'TEAM_MANAGER')
  async exportPdf(
    @Param('id') id: string,
    @Req() req: any,
    @Res() res: Response,
  ) {
    // Fetch the full report (reuses existing RBAC checks)
    const report = await this.reportsService.findOne(id, req.user);

    // Fetch the employees for this team
    const employees = report.team?.employees || [];

    // Fetch the latest risk snapshots for these employees
    const riskSnapshots =
      await this.reportsService.getReportRiskSnapshots(id);

    // Generate the PDF
    const pdfBuffer = await this.pdfService.generatePdf(
      report,
      employees,
      riskSnapshots,
    );

    // Audit log
    await this.reportsService.logPdfExport(id, req.user.sub);

    // Build a clean filename
    const teamName = (report.team?.name || 'report')
      .replace(/[^a-zA-Z0-9]/g, '-')
      .toLowerCase();
    const date = new Date().toISOString().split('T')[0];
    const filename = `hr-insight-${teamName}-${date}.pdf`;

    // Send the PDF as a download
    res.set({
      'Content-Type': 'application/pdf',
      'Content-Disposition': `attachment; filename="${filename}"`,
      'Content-Length': pdfBuffer.length,
    });

    res.end(pdfBuffer);
  }
}
```

### Step C: Add helper methods to ReportsService

Add these two methods to `backend/src/reports/reports.service.ts` (at the bottom, before the closing brace):

```typescript
  // ─────────────────────────────────────────────────────────────────
  // PDF support methods
  // ─────────────────────────────────────────────────────────────────

  /**
   * Get the risk snapshots associated with a specific report.
   *
   * Finds snapshots created on the same date as the report for
   * employees in the report's team.
   */
  async getReportRiskSnapshots(reportId: string) {
    const report = await this.prisma.report.findUnique({
      where: { id: reportId },
      include: {
        team: {
          include: { employees: { select: { id: true } } },
        },
      },
    });

    if (!report) return [];

    const employeeIds = report.team?.employees.map((e) => e.id) || [];

    // Get the most recent snapshot for each employee
    // (there may be multiple from different report generations)
    const snapshots = await this.prisma.riskSnapshot.findMany({
      where: {
        employeeId: { in: employeeIds },
      },
      orderBy: { snapshotDate: 'desc' },
    });

    // Deduplicate: keep only the latest snapshot per employee
    const latestByEmployee = new Map<string, any>();
    for (const snap of snapshots) {
      if (!latestByEmployee.has(snap.employeeId)) {
        latestByEmployee.set(snap.employeeId, snap);
      }
    }

    return Array.from(latestByEmployee.values());
  }

  /**
   * Log a PDF export event to the audit log.
   */
  async logPdfExport(reportId: string, userId: string) {
    await this.prisma.auditLog.create({
      data: {
        userId,
        action: 'EXPORT_PDF',
        entityType: 'Report',
        entityId: reportId,
        metadata: { action: 'PDF export' },
      },
    });
  }
```
